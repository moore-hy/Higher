# 4. WebView2 Release Decision

## 4.1 Final v1.0.0 decision

Change:

```json
"webviewInstallMode": {
  "type": "offlineInstaller"
}
```

to:

```json
"webviewInstallMode": {
  "type": "downloadBootstrapper"
}
```

No alternative.

---

## 4.2 Why

The release goal is a lightweight Setup.exe.

Tauri's official Windows distribution model describes:

```text
downloadBootstrapper:
- requires internet only if WebView2 must be installed
- adds 0 MB WebView2 payload to installer
- default lightweight strategy

offlineInstaller:
- works offline
- adds roughly 127 MB WebView2 payload
```

Higher v1.0.0 targets ordinary Windows 10/11 desktop users and does not require offline deployment.

Tradeoff accepted:

```text
If WebView2 already exists:
→ Higher installs normally.

If WebView2 is missing:
→ Setup may download the WebView2 bootstrapper from Microsoft.

If the machine has no WebView2 AND no network:
→ v1.0.0 lightweight installer is not guaranteed to install.
```

Do not silently revert to offlineInstaller to improve offline compatibility.

Do not use:

```text
skip
fixedRuntime
embedBootstrapper
offlineInstaller
```

for the official v1.0.0 artifact.
