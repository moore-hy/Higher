# Higher UI Constitution

> DEV-0055 PART 3 §11 · 永久产品规则（冻结）

1. 用户打开 Higher 是为了学习，不是为了管理 Higher。
2. 每个页面只回答一个主要问题。
3. 首页最重要的问题永远是："我现在要做什么？"
4. 高频行为必须直接可见。
5. 低频管理行为才进入 `⋯`。
6. 数据库复杂度不能暴露成 UI 复杂度。
7. 数据只有具备理解价值、决策价值、成长反馈价值或异常提醒价值才展示。
8. 没有必要的数据不展示。
9. 没有证据的数据不评分。
10. 没有数据时显示有意义空状态，不显示一屏 `0`。
11. 同一个事实默认只出现一次。
12. 高级能力渐进出现。
13. AI 随叫随到，但不能压过学习本身。
14. 学习结束必须得到即时真实反馈。
15. 所有"爽感"必须能够追溯到真实学习证据。
16. 颜色不能代替信息层级。
17. 字体大小不能随意变化。
18. 页面默认信息应尽可能在 5 秒内读懂。
19. 用户永远可以不建 Goal、不建 Knowledge 直接快速学习。
20. Higher 可以复杂，但用户每天的动作必须简单。

## 数据展示四问（PART 42 §155）

每个数据必须通过四问之一，四个都是"否"→ 不展示：
1. 用户看完立即能理解吗？
2. 它能帮助用户做决定吗？
3. 它能让用户真实感到积累吗？
4. 它是在提醒一个异常吗？
