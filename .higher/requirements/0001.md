## 需求概述

Higher 是一款面向考研学生的**个人学习规划与执行管理桌面软件**，定位为"个人考研学习操作系统"。

核心目标是建立一套完整的学习闭环：

```
考研目标 → 学科体系 → 知识体系 → 学习计划 → 每日任务 → 学习执行 →
题目训练 → 学习记录 → 掌握度分析 → 薄弱点分析 → 计划调整 → 再次学习
```

## 第一阶段核心科目

- 数学
- 英语
- 408（计算机专业基础综合）

政治及自定义科目作为可扩展接口保留。

## 目标平台

- 当前版本仅适配：Windows 11
- 暂不开发：Linux / macOS / Android / iOS / Web 在线版

## 技术路线

### 主程序

- React + TypeScript + Vite
- Tauri 2
- Rust
- SQLite

架构：React UI → TypeScript 应用逻辑 → Tauri → Rust 后端 → SQLite

第一阶段采用本地优先（Local-first）设计，不依赖云服务器、用户账号、在线数据库、云同步。

### 安装工具（未来单独开发）

- C# + .NET
- 负责：检测 Windows 11、检测运行环境、下载缺失依赖、自动配置、部署主程序、创建快捷方式
- 本次严禁开发安装工具
