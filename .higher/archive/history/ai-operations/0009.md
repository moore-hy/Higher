## 1. 任务目标

建立 Higher 最顶层本地学习容器 StudyProfile（学习档案）：

- 多档案数据完全隔离（Goal / Knowledge / Planning / Task / Session / Evaluation）
- 首次启动引导创建第一个档案，创建后自动进入
- settings.active_profile_id 记住最后使用的档案，重启自动恢复
- 档案切换 / 退出（不关闭程序）；存在 active Session 时阻止切换
- 档案日历：由真实学习数据自动聚合，不做手动打卡
- Migration v005 + 旧数据安全迁移（禁止删库）

## 2. 迁移前 Schema

```text

        study_sessions / study_stages / plans / evaluations
goals 无 profile_id 列。
```

## 3. Migration v005（v005_study_profiles.rs）

- 新建 `study_profiles` 表（name / profile_type / target_description / target_date / current_situation / notes / status / last_opened_at / metadata_json + 时间戳；idx_study_profiles_status 索引）
- `goals` 增加 `profile_id`（FK→study_profiles SET NULL）；PRAGMA table_info 检测列存在再 ALTER（幂等）
- 旧数据迁移：有 profile_id IS NULL 的 Goal → 自动创建默认档案"已有数据"并统一关联 + 写入 active_profile_id；无旧 Goal → 不创建默认档案
- 未修改 v001~v004
- **桌面实机验证**：`npm run tauri dev` 日志输出 `[migration] v005: migrated 1 old goal(s) into default profile id=1`，旧 dev 库升级成功

## 4. StudyProfile 数据模型

通用字段（不写死考研/考公专属字段）：profile_type / name / target_description / target_date / current_situation / notes + status(active/archived) + last_opened_at + metadata_json（预留，未建 Metadata Engine）。

## 5. 旧数据迁移策略

仅 goals 持有 profile_id；其余实体链式追踪（LearningItem→Goal→Profile；Task→LearningItem→Goal→Profile；Session/Evaluation 同理），避免给所有表冗余加列。

## 6. Active Profile

复用 settings 表 key=active_profile_id。set_active 同时 touch last_opened_at；get_active 对无效值返回 None；clear_active 只删 key 不删档案。

## 7. Profile Scope（Repository 层防护，非仅 UI 隐藏）

- GoalRepository：list_by_profile / belongs_to_profile；create 必须传 profile_id
- LearningItemRepository：list_by_profile
- TaskRepository：list_today_by_profile / list_all_by_profile
- StudySessionRepository：list_recent_by_profile / has_active_session
- EvaluationRepository：list_recent_by_profile
- 旧的非 scope 接口保留（测试/管理用途），V1 UI 全部走 *_by_profile

## 8. Repository

新增 `repository/study_profile.rs`：create / get / list / update / set_active / get_active / clear_active / touch_last_opened / count / get_calendar（Session+Task+Evaluation 三路 UNION 按天聚合，含 study_seconds / session_count / task_count / completed_task_count / evaluation_count）。
