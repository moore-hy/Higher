# AI 操作记录 0019 - DEV-0019：DeepSeek AI Foundation + AI Context（BATCH-02 4/6）

## 1. 架构

React → Tauri Command（ai_analyze）→ Rust ai/ 模块 → DeepSeek。
前端永不直连 AI。模块：ai/{mod,client,context,prompts,tools}.rs（不塞 lib.rs）。

## 2. client.rs

- reqwest（json + rustls，无 SDK）；Bearer 鉴权（Key 仅来自 settings）
- OpenAI-compatible /chat/completions；response_format json_object（程序解析场景）
- Thinking：开启时模型名加 -thinking 后缀（出错人话提示，不写死业务）
- 人话错误：401/402/404/429/5xx/超时/连接失败/JSON 异常；120s 超时

## 3. Context Builder（context.rs）

- 前端只传 profile_id + action + 可选 session_id/item_id/user_instruction；
  后端验证 Profile Scope 后读库（前端不做 raw dump）
- 六个 scope：session_analysis / knowledge_analysis / planning_analysis /
  today_suggestion / profile_analysis / knowledge_organize —— 各只加载所需数据
- Context Budget：公共头部（Profile/Goal/Stage/知识树结构/最近10条 Session 摘要）+
  按 action 追加（Session Note 12000 字上限 / 当前 Knowledge content 12000 字 /
  子节点摘要300字 / 最近笔记1500字×5 / 附件仅 metadata）
- 附件只发文件名/caption/类型（**不假装理解图片视频像素**）

## 4. Read Tools（tools.rs）

- 10 个只读工具：get_profile_summary / get_current_goal / get_current_stage / list_plans /
  list_knowledge_tree / read_knowledge_item / list_recent_sessions / read_session /
  list_recent_evaluations / get_progress_summary（**无任何写工具**；未知工具拒绝）
- Tool loop 仅 profile_analysis；最多 6 轮；每轮同步短锁执行查询（不跨 await 持锁）；
  超限用已有信息作答

## 5. Structured JSON

ai_analyze：JSON 校验 + **一次**结构修复重试（禁止无限重试）；markdown 围栏剥离。
thinking 参数与 model 错误均人话透传。

## 6. AI 永不写库

分析阶段零写操作；Proposal 由前端用户确认后走正式 Repository（见 0021）。
