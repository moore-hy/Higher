```text

```


# 16 · 为什么压暗程度不允许 100

因为：

```text
壁纸强度 0
```

已经表达：

```text
完全不显示图片
```

如果压暗允许 100：

```text
两个控件表达同一结果
```

产品语义重复。

所以：

```text
overlay max = 80
```
