## 3. 数据库设计（v002）

新增 4 张业务表（迁移脚本 `src-tauri/src/migrations/v002_core_models.rs`）：

```sql
CREATE TABLE goals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    description TEXT,
    status TEXT NOT NULL DEFAULT 'active',
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE learning_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    goal_id INTEGER NOT NULL,
    parent_id INTEGER,                                -- 预留层级，本轮 UI 不实现树
    name TEXT NOT NULL,
    description TEXT,
    mastery_status TEXT NOT NULL DEFAULT 'not_started',
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (goal_id)   REFERENCES goals(id)          ON DELETE CASCADE,
    FOREIGN KEY (parent_id) REFERENCES learning_items(id) ON DELETE CASCADE
);

CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    learning_item_id INTEGER NOT NULL,
    title TEXT NOT NULL,
    planned_date TEXT,
    status TEXT NOT NULL DEFAULT 'pending',
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (learning_item_id) REFERENCES learning_items(id) ON DELETE CASCADE
);

CREATE TABLE study_sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER,                                   -- 可空，允许独立学习
    learning_item_id INTEGER NOT NULL,
    started_at TEXT NOT NULL,
    ended_at TEXT,
    duration_seconds INTEGER,                          -- 结束时由 SQLite strftime 计算
    status TEXT NOT NULL DEFAULT 'active',
    note TEXT,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    updated_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (task_id)          REFERENCES tasks(id)          ON DELETE SET NULL,
    FOREIGN KEY (learning_item_id) REFERENCES learning_items(id) ON DELETE CASCADE
);
```

设计要点：
- 全部使用 `CREATE TABLE IF NOT EXISTS` 保证 v002 自身幂等
- 外键 + 级联规则：删 Goal → 级联删其 Item → 级联删其 Task / Session；删 Task → Session 的 task_id 置 NULL（不丢历史学习记录）
- `mastery_status` 默认 `not_started`，UI 可改为 `learning` / `mastered`
- `study_sessions.status` 默认 `active`，结束学习时改为 `completed`
- 时间统一使用 SQLite `datetime('now')`（UTC），前端 `utils.ts` 转 local 显示
- 严格遵守 TASK.md：不写死考研 / 数学 / 英语等学科字段；Status / Note 不单独建表

## 10. 出现的问题与处理方式

### 问题 1：cargo check 报 `can't find crate for tauri_macros`

- 现象：第一次 `cargo check` 时报 `error[E0463]: can't find crate for 'tauri_macros'`，但日志显示 tauri-macros 已编译
- 排查：查 Cargo.lock 发现 tauri=2.11.5 / tauri-macros=2.6.3；查 docs.rs tauri 2.11.5 Cargo.toml.orig 确认这是 tauri 官方依赖组合（tauri 与 tauri-macros 版本不同步是正常），排除 lockfile 错误
- 处理：`cargo clean` 清理 5.1 GiB 构建产物，重新 `cargo check` 一次性通过。判定为之前 DEV-0002 残留的增量编译缓存损坏，非代码问题

### 问题 2：cargo 不在终端 PATH

- 处理：所有 cargo 命令前先 `$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"`（用户在 INIT-0001 期间手动用 rustup 安装，未加系统 PATH）

### 问题 3：cargo update 没有改变版本

- 现象：`cargo update -p tauri` 后 tauri-macros 仍是 2.6.3
- 结论：这是正确的（tauri 2.11.5 依赖 tauri-macros = "2.6.3"），无需变更。回到 `cargo clean` 路径解决问题
