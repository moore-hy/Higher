## 3. 操作过程与关键决策

### 3.1 迁移 v004（evaluations 表）

- `src-tauri/src/migrations/v004_evaluations.rs`：单事务建表 + 3 条索引
- 关键字段设计：
  - `goal_id NOT NULL` + FK CASCADE（Goal 删除级联清理全部验证记录）
  - `learning_item_id NULLABLE` + FK RESTRICT（存在 Evaluation 时无法误删学习对象；NULL 表示"全科/阶段级验证"不绑具体 Item）
  - `total_items / correct_items / incorrect_items / score / max_score` 全 NULLABLE —— Recall 与 Application 可以不填题数/分数
  - `occurred_at` 独立于 `created_at`，允许把发生时间写成"今天下午"而非落库时间
  - `outcome` TEXT，默认 `unrated`（四种：passed/partial/failed/unrated），避免 bool 与 enum
- 注册到 `migrations/mod.rs` MIGRATIONS 数组末尾（v004，name=evaluations）

### 3.2 EvaluationRepository + 跨 Goal + count/score 校验

- `src-tauri/src/repository/evaluation.rs`：
  - create / get / list_recent(limit) / list_by_goal / list_by_learning_item / update / delete
  - **跨 Goal 防护**：create 时若 `Some(learning_item_id)`，先查 `learning_items.goal_id` 与传入 `goal_id` 是否匹配，不匹配返回 Err 中文信息（含"跨 Goal"/"不一致"字样）
  - **count/score 校验**：抽出 `validate_counts_and_scores` 静态函数，create 与 update 共用；所有值域错误消息用固定格式"xxx 不能为负数" "correct(8)+incorrect(5) > total(10)" "score(120) > max_score(100)"，便于前端识别后直接原样展示

### 3.3 LearningItem safe_delete 扩展（Evaluation 关联即拒删）

- `src-tauri/src/repository/learning_item.rs::safe_delete`：原有三段检查（子项/Task/Session）之后追加 Evaluation 段：
  - `SELECT COUNT(*) FROM evaluations WHERE learning_item_id = id`
  - count > 0 → Err：含"验证记录"字样的中文说明
- 此约束与 evaluations.learning_item_id ON DELETE RESTRICT 形成双重保护（Repository 层面先拦截，返回更好的错误；数据库层面兜底线）

### 3.4 Tauri commands × 7

- `src-tauri/src/lib.rs` 新增：
  - `create_evaluation(goal_id, learning_item_id?) → Evaluation`
  - `get_evaluation(id) → Option<Evaluation>`
  - `list_recent_evaluations(limit=100) → Vec<Evaluation>`
  - `list_evaluations_by_goal(goal_id) → Vec<Evaluation>`
  - `list_evaluations_by_learning_item(learning_item_id) → Vec<Evaluation>`
  - `update_evaluation(id, ...) → ()`
  - `delete_evaluation(id) → ()`
- 所有命令接受可空类型参数（Option），Rust→TS 绑定一致

### 3.5 前端 TS/API/Evaluations 页

- `src/types.ts`：新增 `Evaluation` 接口 + `EvaluationType = "practice"|"test"|"recall"|"application"` + `Outcome = "passed"|"partial"|"failed"|"unrated"` + 常量字典（`EVALUATION_TYPES` / `EVALUATION_TYPE_LABELS` / `OUTCOMES` / `OUTCOME_LABELS`）
