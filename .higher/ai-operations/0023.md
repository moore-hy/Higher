## 1. Universal Assistant（全局通用助手）

- 定义：Higher AI = 全局学习助手，属于整个 Higher，不属于任何页面/模式
- 打开 Panel 即可直接自然语言提问（"我最近都学了什么？""帮我看看极限这个知识点"
  "根据现在的情况我下一步适合学什么？"），不依赖固定 AI Action；五页面快捷按钮全部保留
- AI 可不调用工具回答纯概念问题；数据依赖问题必须先查真实数据（System Prompt Data-dependent Guard）

## 2. Mode Independence

- AI 核心（AiAction/context/tools/prompts）无 profile_type / mode 分支
- 单一实现：HigherAI + Profile Context（无 ExamAI/GeneralAI，无第二面板）
- 测试：general 与 exam 两种 profile_type 档案 assistant_chat 行为一致、各自数据隔离

## 3. Context Semantics（页面默认对象；上下文不是权限）

- Today/Planning/Review/Progress：profile/goal（Review 额外上报观察窗口：今天/本周/当前阶段）
- Knowledge：+ 当前 learning_item；Learning Workspace：+ item + session
- assistant_chat 注入页面附带的 session 笔记与知识正文——"这里"=当前知识节点、"这次学习"=当前会话，
  用户无需再 @；档案级工具仍全部可用（上下文不限制读取范围）
- 跨 Profile 的 session/item 附带依旧拒绝（validate_optional_ids 对所有 action 生效）

## 4. Tools（10 → 11）

  id/title/planned_date/status/learning_item_id/knowledge/goal_id/from_plan（无内部字段）

- JSON 校验 + 聊天协议类型校验；失败一次修复重试（attempt≤2，禁止无限）
- 后端 AssistantChatResponse::parse（围栏剥离/类型校验/非法类型拒绝）+ 前端解析兜底

## 7. Chat → Knowledge Proposal

- System Prompt 明确触发条件：仅用户明确表达"改变正式 Knowledge"意图（整理到/写入/新增到知识库）
  才返回 knowledge_proposal；"帮我总结一下"一律 message
- Panel：chatType=knowledge_proposal 消息显示 [查看变更（N 项）] → 内嵌现有 AiProposalReview
  （Apply 权限不变：仅 update_content/create_child；用户接受/编辑后接受/拒绝）
- 未 apply：数据库零变化（测试断言 content 与节点数不变）；拒绝后对话保留，可继续生成新 Proposal
- Proposal Guard：前端 allowedIds + 后端 Profile/Goal 双守卫保持

## 8. 权限边界（保持）

- AI 不改 Plan：用户"帮我改规划"→ 只给文字版建议 + 提示手动调整（本轮明确不做 Plan Apply）
- AI 不改 Session Note：只生成建议文本（永久）
- 无 Vision：用户问图片/视频 → AI 如实说明只能看到附件元数据，不假装看懂

## 9. Diagnostics（真实调试能力）

- Panel 每条 AI 消息可折叠"本次请求详情"：Provider / Model / Scope(action) / 工具调用次数与轮数
  （上限 6）/ prompt·completion·total tokens / 耗时 ms
- 错误消息可展开"技术详情"（安全处理后的原始错误 + 防御性 Bearer/sk- 掩码 + 600 字截断）
- 禁止且实测断言：诊断序列化不含 api_key / Authorization / Bearer / sk-
