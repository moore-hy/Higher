## 5. Repository 修改

文件：`src-tauri/src/repository/learning_item.rs`

新增方法（不破坏 DEV-0003 旧接口）：

| 方法 | 作用 | 关键点 |
|---|---|---|
| `create_root(goal_id, name, description)` | 创建根节点（parent_id = NULL） | SQL `INSERT ... VALUES (?1, NULL, ?2, ?3)` |
| `create_child(goal_id, parent_id, name, description)` | 创建子节点 | **含跨 Goal parent 防护**：先查 parent.goal_id，若不存在或与新节点 goal_id 不匹配 → 返回 Err |
| `list_by_goal(goal_id)` | 按 Goal 隔离查询全部 item | `WHERE goal_id = ?1 ORDER BY id` |
| `get_children(parent_id)` | 查直接子节点（单层） | `WHERE parent_id = ?1 ORDER BY id` |

旧接口保留：

- `create(goal_id, name, description, parent_id: Option)`：分发到 `create_root` / `create_child`，DEV-0003 测试仍用此接口
- `list()` / `get(id)` / `update_status(id, status)`：保留，Tasks / Today 页继续使用

辅助函数 `parse_learning_item(row)` 抽出（统一 8 列顺序解析，消除重复）。

跨 Goal 防护实现：

```rust
let parent_goal_id: i64 = self.conn.query_row(
    "SELECT goal_id FROM learning_items WHERE id = ?1",
    params![parent_id], |row| row.get(0),
).map_err(|e| match e {
    rusqlite::Error::QueryReturnedNoRows =>
        rusqlite::Error::InvalidParameterName(format!("parent_id {} 不存在", parent_id)),
    other => other,
})?;

if parent_goal_id != goal_id {
    return Err(rusqlite::Error::InvalidParameterName(format!(
        "跨 Goal parent 被拒绝：parent(goal_id={}) 与新节点(goal_id={}) 不一致",
        parent_goal_id, goal_id
    )));
}
```

## 14. 遇到的问题与解决方式

### 问题 1：`Cannot find namespace 'JSX'`（TypeScript）

- 现象：`npx tsc --noEmit` 报 `src/pages/LearningItems.tsx(168,55): error TS2503: Cannot find namespace 'JSX'`
- 原因：React 19 + 新版 TS 配置下，全局 `JSX` 命名空间不再默认可用
- 解决：将 `renderNode` 返回类型从 `JSX.Element` 改为 `ReactElement`，从 `react` 导入 `type ReactElement`
- 验证：再次 `npx tsc --noEmit` 通过

### 无其他问题

DEV-0003 已经解决过 cargo PATH / tauri-macros 缓存 / 沙箱 AppData 等问题，本轮均未复现。
