# 1. P0 · Dedicated Planner 必须读取新正式事实

当前 `run_chat_turn` 规划分支仍以：

```text
read_goal_state()
→ old Final Goal Brief
```

作为正式 gate。

修复为：

## Blueprint Planning Truth Context

在**现有** `ai/planner.rs` 中新增/复用一个明确函数：

```text
build_planning_truth_context(conn, profile_id)
```

必须读取：

```text
confirmed PersonalProfile
active GoalTarget(s)
ready/selected PlanningSource(s)
active PlanningBlueprint（若有）
trusted recent StudySession
trusted Evaluation/Evidence
```

### Goal rules

新 Blueprint Planning：

```text
GoalTarget = 正式目标主源
```

旧 Final Goal：

```text
仅 legacy fallback / migration evidence
不得覆盖 active GoalTarget
不得因为旧 Brief 不完整阻塞已经完整的 GoalTarget
```

考研：

- active REACH 存在 → 主规划目标；
- SAFETY 可作为 risk 下限；
- 缺 REACH 时 Planner 可以提出 clarification；
- 不自动把 legacy Goal 变 active GoalTarget。

### Prompt

Dedicated Planner instruction 明确包含：

```text
【Confirmed PersonalProfile】
【Active GoalTargets】
【Selected Planning Sources】
【Current Active Blueprint】
【Trusted Learning Evidence】
```

不得只写“请基于我的资料”但实际没有正文。
